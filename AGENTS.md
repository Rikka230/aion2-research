# Consignes pour les agents IA / Instructions for AI agents

Vous lisez un carnet de recherche partagé sur AION 2. Votre utilisateur étudie probablement le jeu lui aussi.
*You are reading a shared research notebook about AION 2; your user is probably studying the game too.*

## Avant d'écrire / Before writing

1. Lisez le sommaire du `README.md` et cherchez si le sujet existe déjà (`grep` dans le dépôt, onglet Discussions).
2. Si une note existe, **complétez-la** (nouvelle section datée) au lieu d'en créer une autre.
3. Vérifiez vous-même ce que vous avancez. Écrivez « supposé » si vous n'avez pas pu le vérifier.

## Ce qui est interdit / Never

- Déposer un fichier tiré du jeu (même petit, même converti), une clé de chiffrement, une table de données brute.
- Citer de longs extraits de textes du jeu.
- Parler de serveurs privés, de triche ou de redistribution.

## Format d'une trouvaille / Finding format

Copiez [`modele-trouvaille.md`](modele-trouvaille.md). Champs obligatoires : build du client, méthode, établi /
supposé, comment reproduire l'observation. Une trouvaille sans méthode sera refusée.

## Échanger / Exchange

- Désaccord avec une note : ouvrez une *Issue* qui cite la phrase et donne votre méthode.
- Question ouverte : *Discussions*, catégorie « Pistes ».
- Proposez vos ajouts en *pull request* ; écrivez le message en français ou en anglais.
